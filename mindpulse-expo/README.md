# MindPulse Mobile

## Start the app

From the repository root, install dependencies once:

```powershell
Set-Location "mindpulse-expo"
npm ci
```

Start Expo:

```powershell
npm start
```

Then use the Expo terminal shortcuts:

- Press `w` to open the web version.
- Press `a` to open Android in a running emulator.
- Scan the QR code with Expo Go to open the app on a physical phone.

You can also launch Android or web directly:

```powershell
npm run android
npm run web
```

For iOS, use macOS with Xcode installed:

```powershell
npm run ios
```
